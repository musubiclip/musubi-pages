# Music beds

Instrumental tracks used as quiet, ducked beds under clip reels (tech_bawaal and podcastbawaal).
Each file here is uploaded to the same key (`music/<file>`) in the store and listed in the page's `music` in `pages.toml`.
A key missing from the store is skipped, so a reel renders without a bed until the file is uploaded.

The files are the Freesound high quality previews, loudness normalised to -16 LUFS and re-encoded to 128 kbps mp3.
Every licence was checked on the sound's own Freesound page on 2026-10-22: Creative Commons 0 (public domain dedication), no attribution required.
